Set up Firebase AI Logic to generate real briefs

Briefly is not connected to a Firebase project yet, so it cannot call Gemini. This takes about 5 minutes and stays on the free Spark plan:

  1. Create a project at console.firebase.google.com.
  2. Open Build > AI Logic and click Get started.
  3. Choose the Gemini Developer API backend.
  4. In Project settings > General, copy your web app's config into src/firebase-config.js (or set VITE_FIREBASE_* env vars before building — see README).
  5. For local development, App Check uses the debug provider: run the app once, copy the debug token from the browser console, and register it under App Check > Apps > Manage debug tokens.
  6. Reload this page and press Generate brief again.

No Firebase project? Add ?demo=1 to the URL to try the simulated demo flow instead — no account needed.
